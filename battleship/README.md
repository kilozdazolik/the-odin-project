# Battleship

Interactive Battleship game implemented with HTML CSS and JavaScript

This project is a browser based implementation of the classic Battleship game. It demonstrates modular game logic unit testing DOM manipulation and a simple user interface for placing ships and taking turns

## Features

- **Smart AI Opponent:** Play against a computer that uses Parity Search (checkerboard pattern) for efficient scanning and Hunt Mode (local search) to sink ships upon the first hit.
- **Two-Player Mode:** Local hot-seat gameplay against a human opponent in the same browser.
- **Modern Architecture:** Built with Vite for blazing-fast development and optimized bundling.
- **Modular Design:** Game logic is cleanly separated into Gameboard, Player, and Ship modules.
- **Unit Testing:** Core game mechanics are fully covered by unit tests to ensure reliability.
